# - Рыбалка
## 1. Добавить секретные локации рыбалки
Условно где то на карте появляется локация секретной рыбалки и там +20% к луту, и есть рыбы которые можно поймать только там, каждые 15-30 минут локация меняет своё место.
Чтобы продавать рыбу с секретной рыбалки должен быть секретный рыбак где то в пизде мира
